Latest readings, over HTTP

The latest value of every point of the devices this output serves, as JSON. Values live in memory only: after a restart the API is empty until the first poll. The OpenAPI 3.1 description can be imported into Postman, Bruno or any OpenAPI tool.

Authentication

If the output has a token, every /api/… request needs the header Authorization: Bearer <token>, otherwise the answer is 401 {"error": "unauthorized"}. This page, /openapi.json and /healthz are always open.

Values

valueNumber, bool or string; null for NaN and infinite values.
timestampWhen the device answered: UTC, RFC 3339 with nanoseconds.
age_msMilliseconds since timestamp. A device that stops answering keeps its values while their age grows.

Endpoints

GET/api/devices token if set

All served devices, sorted by name. points counts the points with a value, age_ms is the age of the newest one (null before the first reading).

200Devices 
{"devices": [
  {"device": "inverter", "points": 3, "age_ms": 820},
  {"device": "meter", "points": 0, "age_ms": null}
]}
401Missing or wrong token 
{"error": "unauthorized"}
curl -H "Authorization: Bearer $TOKEN" http://localhost:8080/api/devices
GET/api/devices/{device} token if set

The latest value of every point of a device; points is empty before the first reading.

ParameterDescription
